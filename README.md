# Date Bookmark Manager

ブックマークを日付ごとに自動で整理する Chrome 拡張機能です。

## 概要

この拡張機能は、ブックマークを「YYYY-MM-DD」形式の日付フォルダに自動的に分類し、月が替わると前月分のフォルダを「YYYY-MM」形式の月別フォルダにアーカイブします。溜まりがちなブックマークを時間軸で整理するのに役立ちます。

## 主な機能

- **日付別フォルダへの保存**: 右クリックメニューから、現在のページやリンクを当日の日付フォルダ（例: `2026-01-21`）に保存できます。
- **自動フォルダ整理**: 拡張機能の起動時やブックマーク保存時に、前月以前の日付フォルダを自動的に月別フォルダ（例: `2025-12`）へ移動します。
- **必要なときだけフォルダを作成**: 当日の日付フォルダは、ユーザーが実際にブックマークを保存したタイミングで自動的に作成されます。中身が空のフォルダが先行して作られることはありません。
- **カスタマイズ可能な設定**: オプション画面から、日付フォーマット（6種類）と右クリックメニューの言語（日本語 / English / 简体中文 / 한국어）を選べます。

## インストール方法

1. このリポジトリをクローンするか、ZIPファイルをダウンロードして解凍します。
2. Google Chrome を開き、アドレスバーに `chrome://extensions` と入力して移動します。
3. 右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」ボタンをクリックし、解凍したフォルダを選択します。

## 使い方

1. 任意のページまたはリンク上で右クリックします。
2. メニューから「**日付フォルダにブックマークする**」を選択します。
3. ブックマークバーなどに当日の日付フォルダが作成され、そこにブックマークが追加されます。
